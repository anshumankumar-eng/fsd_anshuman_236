CogniCare

AI-Assisted Early Cognitive Screening Tool

About CogniCare

CogniCare is a proof-of-concept tool designed to assist healthcare professionals in early screening for cognitive impairment by analyzing clock drawings.

Important Disclaimer: This tool is for screening purposes only and is not a diagnostic tool. Always consult a qualified healthcare professional for a comprehensive evaluation.

How It Works

Draw a clock with the time set to 11:10
AI analyzes drawing patterns and features
Receive a risk assessment with metrics
All processing happens locally in your browser

The analysis focuses on indicators such as drawing completeness, number placement, hand positioning, and tremors in drawing execution.
